## The three sentences that matter

1. **You may always read, audit, fork, and learn from the source.**
2. **You may not run it as a deployment without a Letter of Software Deployment Approval.**
3. **A permission is real only when it is signed and recorded in the Registry.**

Everything else in this repository is detail.

## Conventions

- **Version:** documents state their version. The current framework version is 1.0.
- **Normative language:** "must" is mandatory, "should" is a strong recommendation, "may" is
  optional permission.
- **Not legal advice:** nothing here substitutes for advice from a lawyer in your jurisdiction.
- **Translations:** Bengali versions are in [`../translations/bn/`](../translations/bn/). English
  prevails.
