# Glossary

Every term used in the framework, with its meaning and where it is defined.

| Term | Meaning | Source |
|---|---|---|
| **Affiliate** | An entity controlling, controlled by, or under common control with another (>50% voting interest) | PASVL §1.1 |
| **Amendment Notice** | A written instrument changing a LOSDA, recorded in the Registry | LOSDA spec §13.1 |
| **Appeals Panel** | Independent panel that hears challenges to licensing and enforcement decisions | `governance/APPEALS.md` |
| **Author** | The natural person or entity holding economic rights in a work | PASVL §1.2 |
| **BSD C** | Bangladesh Software Development Community; the Steward of the framework | PASVL §1.3 |
| **Class (LOSDA)** | The category of a LOSDA that determines its default terms: S, E, I, H, D, A, G, P, R, X, C, M, O | PASVL §10.14 |
| **Commercial Deployment** | A deployment intended to generate, or reasonably expected to generate, commercial benefit | PASVL §1.4 |
| **Condition code** | A shorthand for a standard condition (C1–C16) applied to a LOSDA | LOSDA spec §10 |
| **Continuity LOSDA** | Class C permission issued by the Steward when an author is unavailable and an essential service is at risk | PASVL §9.2 |
| **Contribution** | Any material intentionally submitted to an author or BSD C for inclusion in a work | PASVL §1.5 |
| **Contributor** | A person or entity making a Contribution | PASVL §1.6 |
| **Cure period** | The time allowed to fix a breach after a Notice of Non-Compliance | PASVL §18.4 |
| **DCO** | Developer Certificate of Origin, version 1.1; a sign-off certifying the right to contribute | `CONTRIBUTING.md` |
| **Deployment** | Executing, running, installing for operational purposes, hosting, serving, embedding, flashing, or distributing in executable form | PASVL §1.7 |
| **Deployment Scope** | The totality of permissions in a LOSDA: work, type, territory, field of use, scale, term, conditions | PASVL §1.8 |
| **Derivative Work** | A work based on, incorporating, adapting, translating, modifying, or linking to a work | PASVL §1.9 |
| **Distribution** | Transfer of a copy to another person, in source or executable form | PASVL §1.10 |
| **Effective Date** | The date a LOSDA takes effect, as recorded | PASVL §1.12 |
| **Enforcement Register** | Public redacted record of enforcement actions | PASVL §1.13 |
| **Evaluation Use** | Private, non-commercial, non-production execution, limited to 30 days per year in Mode S | PASVL §1.11, §6.3 |
| **Evaluation Extension** | Class X LOSDA extending or widening Evaluation Use | PASVL §6.5 |
| **Field of Use** | The permitted purpose, product, or market stated in a LOSDA | LOSDA spec §11.4 |
| **Fork** | A copy of a repository created for viewing, experimenting, contributing, or preserving a record | PASVL §1.14 |
| **Hosted Service** | A deployment in which the work's functionality is available to persons other than the deployer | PASVL §1.15 |
| **Issuer** | The Author, or a person/entity authorized to issue LOSDAs | LOSDA spec §5 |
| **Issuer code** | A registered short code appearing in a LOSDA ID | LOSDA spec §8 |
| **LOSDA** | Letter of Software Deployment Approval; the permission instrument | PASVL §1.17 |
| **LOSDA ID** | The permanent identifier, `LOSDA-<ISSUER>-<YYYY>-<NNNNNN>` | LOSDA spec §8 |
| **LOSDA Record** | The authoritative machine-readable registry entry, which prevails over copies | PASVL §1.18 |
| **LOSDA Registry** | The public registry of LOSDAs | PASVL §1.19 |
| **Machine Learning Use** | Using the work as training, tuning, evaluation, embedding, or synthetic-data source | PASVL §1.20 |
| **Merkle root** | A cryptographic digest of the entire registry, published to detect tampering | `governance/REGISTRY-POLICY.md` §3.3 |
| **Modification** | Any change to a work, including refactoring, porting, or configuration that alters behavior | PASVL §1.21 |
| **Mode S / Mode U** | The author's NOTICE setting: S permits Evaluation Use; U forbids execution without a LOSDA | PASVL §6.2 |
| **NNC** | Notice of Non-Compliance; formal notice of a breach with a cure period | PASVL §1.24 |
| **Non-Commercial Purpose** | A purpose not primarily intended for commercial advantage or monetary compensation | PASVL §1.22 |
| **NOTICE** | The author's file stating identity, contact, Mode, and additional attribution terms | PASVL §1.23 |
| **OSI** | Open Source Initiative; publisher of the Open Source Definition | — |
| **PASVL** | Public Availability with Source-Code Visibility License, version 1.0 | `LICENSE` |
| **PASVL/LOSDA framework** | The combined two-instrument system | PASVL Preamble |
| **Perpetual LOSDA** | A LOSDA with no end date, revocable only on limited grounds | PASVL §19.4 |
| **Production Deployment** | Any deployment that is not Evaluation Use and serves real operational purposes | PASVL §1.25 |
| **Publicly Available** | Source accessible to the public without payment, registration, or confidentiality | PASVL §1.26 |
| **Record hash** | SHA-256 of the canonical JSON form of a LOSDA record | LOSDA spec §12.4 |
| **Redistribution** | Distribution to any person, including derivative works and containerized forms | PASVL §1.27 |
| **Registry Custodian** | The officer who operates the Registry | `governance/REGISTRY-CUSTODIAN.md` |
| **Reliance Period** | The 180-day wind-down available after termination or revocation for cause other than breach | PASVL §1.29, §19.2 |
| **Revocation** | Withdrawal of a LOSDA by the issuing authority for cause | PASVL §1.30, §18.7 |
| **Service Bureau Use** | Permitting third parties to use the work's functionality as a substitute for their own LOSDA | PASVL §1.31 |
| **Source-available** | A license category in which source is public but rights are restricted; PASVL is one | PASVL §28.5 |
| **Steward** | BSD C in its framework-governance capacity | PASVL §27.1 |
| **Substantial Portion** | A portion material to the work's functionality, value, or distinctiveness | PASVL §1.35 |
| **Territory** | The geographic, jurisdictional, or organisational area in which deployment is permitted | PASVL §1.36 |
| **Third-Party Components** | Included or required components governed by their own licenses | PASVL §1.37 |
| **Trademarks** | Names, logos, and designations associated with a work or BSD C | PASVL §1.38 |
| **Verification URL** | The stable public URL where a LOSDA's status can be checked | PASVL §1.39 |
| **Violation** | Any breach of the license or a LOSDA, including exceeding its scope | PASVL §1.40 |
| **Visibility Grant** | The public rights in Article 3: read, audit, fork, cite, teach, contribute | PASVL Article 3 |
| **Work** | The software and related materials made available under the license | PASVL §1.32 |
| **You** | The individual or entity exercising rights under the license | PASVL §1.41 |
